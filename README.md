# kaiten-checker

スマホで区間開始、1kごとの回転数、実戦結果を記録するStreamlitアプリです。

数字を入力し、「区間開始」または「1k確定」を押して記録します。当たり・ST終了後は新しい区間を開始でき、複数区間の通常回転を一つの実戦として合算します。誤入力は「直前の1行を削除」で戻せます。

「1k確定」は入力値が前回値より大きい場合だけ記録できます。今回1kが8回転未満または45回転超のときは、入力ミス防止のため確認が表示されます。記録後は入力欄が空になるので、続けて数字だけ入力できます。

ボーダー（回転/k）を入力すると、累計/k・直近5k・直近10kとボーダーとの差を色付きで表示します。ボーダーは保存して次の実戦へ進んでも引き継がれます。

ボーダーを入力すると、直近5k・10kから見切りの目安も表示します（5k以上で判定）。

- 注意：直近5kがボーダー−2以下
- 見切り検討：直近10kがボーダー−2以下
- 見切り：5kごとに2回続けてボーダー−2以下

あわせて、各時点の直近5k・直近10k・累計の「平均−ボーダー」を3本の線でグラフ表示します。累計と直近10kの線が離れてきたら、前半と今とで回転率が変わったサインです。縦軸は±5回転で固定し、超えた点は▲▼で上端・下端に表示します。赤の点線（−2）が見切りラインです。

実戦結果の下の「この実戦の結果」と、画面下の「保存済みデータ」（新しい順）には、手書きで転記しやすいよう次の項目を1項目1行で表示します：総回転数、確変当たり回数、単発当たり回数、総当り回数、初当たり確率（1/○○.○）、総投資玉数、総回収玉数、差玉、回転率、総プレイ時間（保存まで／最後の1kまで）。サマリー表とサマリーCSVも、保存名の次に当たり回数と玉数が並ぶ列順にしています。

プレイ時間は、「区間開始」「1k確定」を押した時刻（日本時間）を記録して計算します。最初の記録から「この実戦を保存して次へ」を押すまでと、最後の1k確定までの2つを表示します。時刻の記録を始める前の実戦は「−」になります。

「保存済みデータを全削除」は確認後に削除されます。

入力途中の内容と「保存済みデータ」はブラウザのlocalStorageへ自動保存され、スマホの暗転や
Streamlitの再接続後に同じブラウザで開くと自動復元されます。

旧版の「開始回転数＋入力表」で保存された入力途中データは、初回読込時に新しい区間履歴へ移行します。
