# kaiten-checker

スマホで区間開始、1kごとの回転数、実戦結果を記録するStreamlitアプリです。

数字を入力し、「区間開始」または「1k確定」を押して記録します。当たり・ST終了後は新しい区間を開始でき、複数区間の通常回転を一つの実戦として合算します。誤入力は「直前の1行を削除」で戻せます。

「1k確定」は入力値が前回値より大きい場合だけ記録できます。

入力途中の内容はブラウザのlocalStorageへ自動保存され、スマホの暗転や
Streamlitの再接続後に同じブラウザで開くと自動復元されます。

旧版の「開始回転数＋入力表」で保存された入力途中データは、初回読込時に新しい区間履歴へ移行します。
