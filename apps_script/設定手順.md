# スプレッドシート送信の設定手順

回転率チェッカーで保存した実戦を、Googleスプレッドシート「回転率チェッカー記録」へ送るための設定です。
最初に1回だけ行います。PCで作業してください。

## 0. 合言葉を決める

アプリ以外から勝手に書き込まれないようにするための文字列です。

- 半角の英数字で20文字以上にします（例：`kc` のあとに思いついた英数字を続ける）。
- **このあと2か所に同じものを入れます。** メモ帳などに一時的に書いておくと楽です。
- チャットやメールには書かないでください。

## 1. 受付窓口のプログラムを貼り付ける

1. Googleドライブで「回転率チェッカー記録」を開きます。
2. メニューの **拡張機能 → Apps Script** を押します。新しいタブが開きます。
3. 最初から入っている `function myFunction() { ... }` をすべて消します。
4. リポジトリの `apps_script/受付窓口.gs` の中身をすべてコピーして貼り付けます。
5. 上の 💾（プロジェクトを保存）を押します。
6. 左上の「無題のプロジェクト」を押して、名前を「回転率チェッカー受付」に変えます（任意）。

## 2. 合言葉を登録する

1. Apps Script の画面左の ⚙（**プロジェクトの設定**）を押します。
2. いちばん下の **スクリプト プロパティ** で「スクリプト プロパティを追加」を押します。
3. 「プロパティ」に `TOKEN`、「値」に 0. で決めた合言葉を入れます。
4. **スクリプト プロパティを保存** を押します。

## 3. ウェブアプリとして公開する

1. 右上の **デプロイ → 新しいデプロイ** を押します。
2. 「種類の選択」の ⚙ を押して **ウェブアプリ** を選びます。
3. 次のように設定します。
   - 説明：`回転率チェッカー受付`（任意）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. **デプロイ** を押します。
5. 「アクセスを承認」を押し、ご自分のGoogleアカウントを選びます。
   - 「このアプリは Google で確認されていません」と出たら、**詳細 → 回転率チェッカー受付（安全ではないページ）に移動** を押します。ご自分で作ったプログラムなので問題ありません。
   - 「許可」を押します。
6. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/……/exec`）をコピーします。

「アクセスできるユーザー：全員」は、アプリから送れるようにするための設定です。合言葉が合わない送信は受付窓口が断るので、URLを知られても書き込まれません。

## 4. アプリに登録する（Streamlit の Secrets）

1. PCで https://share.streamlit.io を開いてログインします。
2. kaiten-checker の行の「⋮」→ **Settings → Secrets** を開きます。
3. 次の3行を貼り付け、`url` に 3. のURL、`token` に 0. の合言葉を入れて **Save** を押します。

```toml
[sheet]
url = "https://script.google.com/macros/s/……/exec"
token = "ここに合言葉"
```

1分ほどで反映されます。

## 5. 動作確認

1. スマホで回転率チェッカーを開き直します。
2. 「保存済みデータ」に **未送信を送る（○件）** ボタンが出ていれば、設定は読み込まれています。
3. ボタンを押して「スプレッドシートへ○件送りました。」と出れば完了です。スプレッドシートの「結果」「履歴」に行が増えます。

## うまくいかないとき

| 表示 | 原因と対処 |
|---|---|
| 「未送信を送る」ボタンが出ない | Secrets が保存されていないか、`[sheet]` の行が抜けています。4. をやり直してください。 |
| 「受け付けませんでした（unauthorized）」 | Secrets の `token` と、スクリプト プロパティの `TOKEN` が一致していません。 |
| 「受け付けませんでした（sheet not found）」 | シート名が「結果」「履歴」から変わっています。名前を戻してください。 |
| 「通信できませんでした」 | 電波が弱いか、URLが違います。URLが `/exec` で終わっているか確認してください。 |

## プログラムを直したとき

`受付窓口.gs` を貼り替えたら、**デプロイ → デプロイを管理 → ✏（編集）→ バージョン：新しいバージョン → デプロイ** を押します。URLは変わりません。
